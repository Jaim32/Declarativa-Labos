# Labo 05.1 - Calculadora de las 4 Operaciones Básicas en Prolog

Calculadora gráfica moderna en **Java Swing** que utiliza **tuProlog** para evaluar las cuatro operaciones básicas:
- **Suma (`+`)**
- **Resta (`-`)**
- **Multiplicación (`*`)**
- **División (`/`)** con protección ante división por cero.

Permite tanto evaluar expresiones completas (ej: `15 + 25`, `(10 + 5) * 2`, `144 / 12`) como operaciones de dos operandos separados por coma (ej: `20, 5`).

## Ejecución
- **Desde IntelliJ IDEA**: Abrir la carpeta `labo-05.1` (como proyecto Maven) y ejecutar `Main.java`.
- **Desde Terminal**:
  ```bash
  ./run.sh
  ```
